# Selfserved AI / AIRM public site

Static presentation and beta application pages for the AIRM project.

The public bundle consists of the HTML pages, six article pages, styles, and browser-side mode interaction under `assets/`. Operational handoff notes and unpublished drafting material are kept outside the deployable source.

## Local preview

Serve this directory with any static web server, for example:

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080/`.
